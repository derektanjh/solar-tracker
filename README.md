# solar-tracker

Tracks actual home electricity usage from TNB bills and NEM solar generation.

Live site: https://derektanjh.github.io/solar-tracker/

- **Actual usage** = Import + Solar generated − Export
- **Add a month:** tap **Add month**, upload the TNB bill PDF (read on your device) and type the solar kWh from the app. Saving writes to `data.json` using a GitHub token stored only in that browser.
- iPhone: open the site in Safari → Share → **Add to Home Screen**.
